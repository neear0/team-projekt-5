POŽIADAVKY NA WEBOVÉ SÍDLO – HTML5

(1 ČASŤ – 50 BODOV)
úvodná stránka (homepage);
ďalšie minimálne 3 podstránky;
stránka – kontakty – kontaktné údaje autora stránky, literárne zdroje;
Stránka bude obsahovať validné html prvky:
html: minimálna štruktúra web stránky
head: kódovanie stránky, title
head: meta informácie k téme web stránky (description, keywords, author)
head: favicon
body: nadpisy aspoň v troch úrovniach
body: strong, em, blockquote, q, cite, kotva, mark, špeciálne symboly, odkazy
body: usporiadaný, neusporiadaný, definičný zoznam, v niektorom z nich budú použité obrázky;
body: obrázok, logo stránky s odkazom na index.html, obrázková mapa
body: sémantická štruktúra: main, header, nav, article, section, aside, footer a pod.
body: funkčná navigácia medzi stránkami
body: validné html súbory
POŽIADAVKY NA WEBOVÉ SÍDLO – CSS3

(2 ČASŤ – 50 BODOV)
Stránka bude obsahovať jeden css súbor uložený v zložke style/style.css / jednotlivé časti kódu musia byť okomentované
selektor ako html, id a class,
farba pozadia, textu, štýlovanie písma,
vonkajší a vnútorný okraj, rám, obtekanie obrázkov,
vhodné vlastnosti CSS budú mať obrázky, napr. po ukázaní kurzorom myšky sa obrázok zväčší, bude mať zaoblené rohy a pod.,
body: tabuľka, v ktorej budú použité aj obrázky,
body: audio, video, obrázok, logo stránky s odkazom na index.html, obrázková mapa
funkčné menu – vertikálne alebo horizontálne
validný css súbor
