Web projektu

  • Člen tímu pripravil web projektu v klasickom HTML a CSS a nasadil ho na GitHub Pages.
  • Web má stránky Domov, Motivačný list, Tím a Vývoj.
  • Stránka Vývoj ukazuje Trello board so stavom úloh (hotové úlohy, termíny, podúlohy), históriu zmien v repozitári a zápisnice. Dáta z Trella ukladá do súboru GitHub Action, takže v repozitári nie sú žiadne prístupové kľúče.
  • Technológie nie sú pevné. Web zostáva zatiaľ v HTML a CSS, UI aplikácie bude pravdepodobne v Astro.

Grafika a logo

  • Členovia tímu pracovali na grafike webu a na logu projektu.
  • Grafická šablóna sa použije aj pri aplikácii, aby mali obe časti rovnaký vzhľad.

Pracovný názov projektu

  • Dohodli sme sa na pracovnom názve Ooko. Názov sa môže ešte zmeniť.

Trello, plán a úlohy

  • Harmonogram na najbližšie týždne je v Trelle, úlohy majú termíny.
  • Najbližší termín je 28. 10. 2026: motivačný dokument (PDF), úvodná prezentácia tímu (PDF) a web projektu (logo, grafická šablóna, stránka Tím, úvodná zápisnica a stránka Dokumenty).
